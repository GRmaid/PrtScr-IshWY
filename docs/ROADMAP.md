## 已定决策（2026-10-18 起）

1. **默认热键（2026-10-22 主人确认）**：v1.0.0 起默认窗口截图 `Alt+A`、全屏快速截图 `Alt+D`；测试期曾用 `F1`/`F2`，旧配置仍按显式 vk 字段读取。软件支持改键与删除。
2. **初始状态（2026-10-22 主人确认）**：默认截图模式为常规截图（所见即所得），默认 Windows OCR（Umi 默认关闭，需手动开启），开机自启动默认关闭，关闭主窗口驻留托盘。
3. **默认热键（历史）**：测试期用单 `F1`；`Alt+A` 当时被主人的微信截图占用，v1.0.0 发布前已由主人确认改用 `Alt+A`。
4. **截图落点**：确认后进**剪贴板**（微信式），贴图功能从剪贴板读取（Snipaste 同逻辑）。
5. **OCR 策略（2026-10-22 起）**：Windows OCR 为内置默认（零依赖）；**Umi-OCR 为可选引擎**，`preferUmiOcr` 默认 `false`，需在设置里手动开启后才连接本机 `127.0.0.1:1224`，未开启或未运行时静默跳过。软件要传播到 GitHub，不能强依赖第三方软件。
6. **UI 必须支持自定义背景**：设置页可选背景图 + 不透明度（M0 已有 v0，后续扩展到取景器/编辑器与模糊效果）。
7. **应用图标**：使用 `tools/gen_icon.py <图片路径>` 从维护者自备图片生成多尺寸 ico（源图不随仓库分发）。
8. **技术栈**：C# / .NET 10 LTS + Windows App SDK 2.5.x（WinUI 3）+ CsWin32；不依赖 Visual Studio，纯 dotnet CLI 构建。
9. **分发**：GitHub 发布，优先 unpackaged 便携版（WindowsAppSDKSelfContained）；v1.0.0 包启用 partial trim 以压低体积。

## 核心技术方案备忘

- **冻屏取景（微信式流畅）**：热键触发 → GDI/WGC 抓全屏静态图 → 不透明全屏窗口显示该图 + 半透明遮罩 + 选区 UI。不用透明窗口，稳且快。
- **窗口识别**：`EnumWindows` Z 序 + `DWMWA_EXTENDED_FRAME_BOUNDS`（精确矩形）+ `DWMWA_CLOAKED`（排除隐藏窗口）。
- **分窗口截屏**：`Windows.Graphics.Capture`，`IsCursorCaptureEnabled=false`、`IsBorderRequired=false`（Win11 支持）；只合成目标窗口自身 → 其他进程悬浮窗天然不入图；被遮挡也能抓完整。
- **区域模式悬浮屏蔽三层**：进程/标题黑名单（wemeetapp.exe、cloudmusic.exe…）→ 启发式（TOPMOST+TOOLWINDOW+分层穿透+小窗打分）→ 纯净合成（按 Z 序逐窗捕获再合成，重建壁纸/图标）。合成器放 M6。
- **Umi-OCR 接入**：HTTP `POST /api/ocr/data`（base64），端口 1224；可用 `Umi-OCR.exe --server --hide` 拉起；接口细节以运行后的 `http://127.0.0.1:1224/docs` 为准。
