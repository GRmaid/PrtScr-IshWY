基线：`e82ad8ee592db61581f400aecf9f9a38ad34424d`。本轮 UI 实现由 Claude 完成，随后在 Windows 上进行独立构建与发布资源检查。

## 改动

- 主页截图动作文案随当前档位、起始模式与倒计时状态更新；设置改用 NavigationView 分组，并调整窄窗布局。

- 补充按钮的可访问名称、状态播报与图标提示。

## 已完成的验证

环境：.NET SDK 10.0.402、Windows SDK 10.0.26100，项目使用 WindowsAppSDK 2.5.1。

- Windows Debug 构建成功：0 错误，2 条相同的 CS0067 警告（DelegateCommand.CanExecuteChanged 未使用）。
- Release x64 自包含、部分裁剪发布成功。输出包含 IshWY.exe、IshWY.pri、图标及 9 个 XBF；无 PDB 或运行数据目录。
- 发布存在 IL2026 警告（JSON 反射序列化与内置 COM）和 IL2104 警告（Windows SDK、WinRT.Runtime、System.Private.Windows.Core）；运行影响尚未验证。
- 提交的 8 个源码文件与已完成构建检查的源码内容一致；未为准备 PR 更改应用代码。

## 尚未完成的验收

真实 UI、截图、读屏、tooltip 与交互流程尚未实机验收。构建和资源检查通过不代表运行验收通过。请合并前重点检查：

- 主页按钮文案与实际动作、设置导航、窄窗、主题和 100% / 125% / 150% 缩放。
- 历史可见 120 张与实际分类数量、删除确认/取消/Esc、重复点击、关闭及确认期间新增截图的保留。
- OCR 复制成功/失败、剪贴板占用、空白内容、复制期间编辑及关闭后回调。
- 读屏名称与状态播报；新增 tooltip 是否遮挡、残留或出现浮动删除提示。
- 启动项、全局热键、托盘及单实例行为。

正常启动会检查并可能更新当前用户的自启动注册，使用固定的单实例事件，并安装钩子、注册全局热键。仅换目录不能隔离这些行为。本轮未启动应用，未执行 `--smoke`。后续运行测试应使用隔离 Windows 账户/会话及合成历史，保留用户原有配置和正在运行的实例。
