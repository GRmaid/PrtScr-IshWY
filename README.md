## 特性

- **唯一有效的一行**：主要是下面的内容都是大肥鱼帮我写的，其实我做这项目就是出于对微信截图的流畅的惊叹，和对OBS的延伸想象，要是截图也能分窗口截图就好了，于是就有了这个
- **冻屏取景**：热键唤起静态帧取景器，指针框选，Enter 或双击完成并进剪贴板，Esc 取消。取景中按 `Tab` 在「窗口截图」和「常规截图」之间切换。
- **两种取景模式**：默认「常规截图」按屏幕所见裁切，右键菜单、悬停提示、下拉框、鼠标指针都能原样截到；切到「窗口截图」则按窗口吸附并重建窗口本体（抗遮挡）。设置 → 截图行为可选择每次从哪种模式起步，取景中按 Tab 仍可临时切换。
- **窗口吸附**：指针指向窗口自动吸附窗口矩形；同一位置有多个窗口时用滚轮循环切换（按 Z 序），窗口局部截图可直接在窗口内拖框。
- **取景 HUD**：底部常驻条显示当前模式与当下可用的操作（Tab 切换、滚轮选窗、回车截图、拖拽框选、右键/Esc 退出），随拖拽、选区、悬停状态变化；有选区时选区外侧出现「✕ 取消 / ✓ 确认 / 文字识别 / 保存」操作条；常规截图的已有选框可直接拖动移动，尺寸与进程提示只保留数据，不堆快捷键说明。
- **窗口内容捕获（抗遮挡）**：PrintWindow / Windows.Graphics.Capture 抓窗口本体，不依赖屏幕合成，被其他窗口盖住也能拿到完整内容。
- **放大取色器**：取景器跟随鼠标显示 19×19 像素放大镜、十字准星与 HEX / RGB；没有选区时按 `Ctrl+C` 直接复制色值（例如 `#FF3A6E`）。有选区时 `Ctrl+C` 仍然是复制截图。纯本地实现，不增加整屏缓冲。
- **原生贴图**：截图钉在桌面最上层，真 per-pixel 透明；拖动移动、滚轮以指针为中心等比缩放（上限当前显示器工作区），左右半屏点击切换历史贴图；拖动时按 8px 吸附工作区与其他贴图。右键菜单可锁定位置、点击穿透、调不透明度（100/75/50/25）、复制、标注、裁剪、识别文字、另存为、打开截图历史、关闭。菜单是自定位的 WinUI 3 面板，跟随系统浅色/深色，点击菜单外只关闭菜单，不会误切换贴图。进入标注后左键绘制，按住中键或右键仍可拖动贴图。
- **贴图裁剪**：右键「裁剪…」在贴图上框选，按 `Enter` 或「贴图」生成一张偏移的新贴图，原贴图保留，不覆盖剪贴板；`O` 识别选区文字，`Ctrl+S` 另存为。裁剪结果可按设置写入「贴图裁剪」历史分类。
- **屏幕贴图管理**：主页历史摘要旁与托盘「屏幕贴图管理」集中查看所有贴图，支持单张复制、另存、OCR、关闭与恢复交互，也可一键隐藏/显示/关闭全部；打开管理窗时会临时降下置顶贴图，选中的贴图不会被管理窗盖住；管理窗只在贴图增删、切换图片或编辑完成时刷新，拖动/缩放贴图不会重建卡片。
- **新贴图初始大小**：设置 → 贴图可把新贴图与左右切换到的历史贴图设为原图 80–100% 起步（默认 100%），超出工作区会自动缩小；已有贴图不变，滚轮仍可继续缩放。
- **原位标注**：在贴图窗口内直接绘制矩形、箭头、画笔、文字、马赛克、序号，支持颜色、HSV 取色、撤销、清空；工具栏按宽度自动分成「工具 + 颜色」和「撤销/清空 | 取消/完成/另存」两组，窄贴图逐级收窄而不会无限换行；文字工具可调 10–96 字号（工具栏「− 字号 N +」或输入框内滚轮），输入框贴合点击位置且与最终字号一致。完成后点「完成」把标注烘焙回贴图并复制，或点「另存」烘焙后另存为 PNG/JPEG。
- **OCR**：默认使用内置 Windows OCR，零依赖；可手动开启本机 Umi-OCR（默认端口 1224）提升精度。取景中按 O、贴图右键、托盘/设置均可触发，结果窗可编辑复制并带应用图标；从设置页或全局热键触发时不会把设置窗一并带到前台。~~UmiOCR真的很好用啊~~
- **全屏快速截图**：任意组合键，静默整屏捕获并写入剪贴板；带全屏游戏兼容处理（感谢大肥鱼和它的DSH；best-effort，也可能不稳定）。
- **截图档位**：主截图热键支持「常规取景」与「快捷全屏」两档。常规取景走冻屏 HUD，快捷全屏则直接抓整屏进剪贴板并写历史，不再弹取景器；设置里选默认档位，`Alt+Shift+C` 可在运行中即时切换（不影响下次启动的默认值）。
- **全局热键**：截图、全屏快速截图、从剪贴板贴图、从剪贴板 OCR、切换截图档位五个动作都能在设置里录制组合键；每行右侧的小 ✕ 可删除当前组合键，删除后显示「未设置」，重启也不会把窗口/全屏截图偷偷回退到默认热键；热键被其他程序占用时设置页会直接提示。
- **开机自启动**：在「设置 → 启动与托盘」一键开启/关闭。开启后登录 Windows 自动静默驻留托盘，不弹窗；只写当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限。
- **截图历史**：框选截图、全屏快速截图与可选的贴图裁剪都会留一份 PNG 在本机 `data/history`；窗口截图会记录所属进程，历史窗先按模式、再按进程分类，另有「常规截图 / 贴图裁剪 / 早期未分类」，每类默认保留 30 张（1–200 可调）；支持单击选中、双击直接贴图、右键进入多选、复制、贴图、标注、删除、清空当前分类、打开文件夹；多选时复制与标注取最新一张，贴图与删除作用于全部选中项；全选后再点一次「取消全选」退出多选，选择模式下点窗口空白处也会退出；「另存为」一个按钮兼顾单张与批量：选一张另存到任意位置，选多张导出到同一文件夹；历史窗打开时新截图会即时出现，底栏上方固定显示当前可做的操作说明，不使用悬浮 tooltip；窗口标题下固定说明「左键选中；右键进入多选」。
- **延时截图**：设置里可选「不延时 / 3 秒 / 5 秒 / 10 秒」。按下截图热键后先等待，方便打开右键菜单、悬停提示、下拉框或摆好窗口，到点再冻结画面；等待期间再按一次截图热键可取消。托盘菜单也有「延时截图」（未配置时默认 3 秒）。
- **鼠标指针开关**：设置里可让截图包含当前鼠标指针，截图取景和全屏快速截图都生效；默认关闭。
- **托盘与设置**：主窗口首页是 2×2 常用操作卡片（窗口截图 / 全屏截图 / 贴图 / 文字识别，右上角显示当前热键）与截图历史摘要；下方按「截图与热键 / 截图行为 / 截图历史 / 启动与托盘 / 外观 / OCR / 关于」分组，五个热键用一张紧凑表格录制与删除。托盘菜单保留延时截图、历史与退出入口。
- **便携**：配置、日志与截图历史都放在程序目录 data/，解压即用；默认不写注册表，只有手动开启开机自启动时才写当前用户 Run 项。

五个全局热键都在「设置 → 截图与热键」的表格里点「修改」后直接按新组合键；`F1`–`F12` 可以单独使用，其他键必须搭配 Ctrl / Alt / Shift / Win。热键是系统级注册，被其他程序占用时设置页会提示注册失败，换一个组合键即可。

每行右侧的小 ✕ 用来删除该快捷键。删除后行内显示「未设置」、✕ 变灰，钩子与 RegisterHotKey 同时注销；窗口截图/全屏截图用配置里的 `-1` 记录「用户主动删除」，所以重启后不会复活默认热键。之后点「修改」随时可以重新录制。

贴图窗口：拖动移动，滚轮以指针位置为锚点缩放，右键打开菜单；左右半屏点击切换上一张/下一张历史贴图（锁定后禁用）。标注时左键绘制，按住中键或右键拖动贴图（右键松开未移动才弹菜单）；文字工具下滚轮改为调字号。

取景器的两种模式共用同一套框选、回车/双击确认、Ctrl+S 另存为和 O 识别流程，只换取图来源：

- **窗口截图**：鼠标指向窗口即吸附（边缘 2px 内也算，方便从窗口边界开始拖框）；单击选中整个窗口，拖拽窗口内部得到窗口局部；滚轮切换同一位置重叠的窗口。选区尺寸提示旁会显示所选窗口的**进程名**（不显示图标），便于确认选中的是哪个程序；写历史时也按该进程归类。滚轮循环到目标窗口后，不用单击，直接按 `Enter` 就截这个窗口（常规模式下同样按高亮窗口矩形从冻结画面裁切）。屏幕上能看到的右键菜单、悬停提示、下拉框也纳入识别，想抓它们时直接框选。原生子对话框（例如 `#32770` 错误框）会被单独列为候选，而不是被父窗口吞掉。
- **常规截图**：同样会高亮光标下的窗口、可单击选中整个窗口，但选区只是从冻结画面裁切，不重建窗口；拖拽可从任意位置（包括窗口边界）开始自由框选，所见即所得，适合抓弹窗、菜单、鼠标指针或任何窗口模式拿不到的内容。

取景器底部有常驻 HUD：左侧蓝框里是 `Tab` 与当前模式（窗口截图 / 常规截图），右侧随状态显示可用操作。`Tab` 随时切换模式；切换时会清空当前选区，并在 HUD 上方弹出提示（例如「已切换到常规截图，原选区已清除」）。有选区时选区外侧会出现「✕ 取消 / ✓ 确认 / 文字识别 / 保存」操作条；`Ctrl+C` 在没有选区时复制放大镜中心的色值，有选区时仍然复制截图。

`Esc` 由统一仲裁器分配：标注中只退出标注、贴图保留；OCR 结果窗与贴图重叠时只关最上层那个，不重叠时固定先关 OCR；OCR 关掉后再按一次 `Esc` 才会关贴图。

## 开机自启动

默认关闭。打开「设置 → 常规」的「开机自动启动（登录 Windows 后静默运行到托盘）」即可：

- 在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入值 `IshWY`，命令为带引号的 `IshWY.exe --startup`，不需要管理员权限。
- 登录后程序以 `--startup` 静默启动，只驻留托盘，不弹设置窗；热键与取景器会随后预热。
- 移动便携目录后，下次启动会自动更新登记的路径。
- 程序只允许一个实例：再次双击 `IshWY.exe` 不会启动第二份，而是唤醒已运行实例的设置窗。
- 关闭开关会删除该 Run 值；`--startup` 是内部参数，不需要手动使用。

## 截图历史

默认开启。每次确认取景或触发全屏快速截图后，程序会把同一份 PNG 写入程序目录的 `data/history`，并写一份同名 `.json` 记录取景模式、窗口进程名、窗口标题与时间：

- 文件名形如 `20261020-121425-539-win-63bbee.png`，中间的 `win` / `normal` / `legacy` 分别表示窗口截图、常规截图、无元数据的历史文件。
- 历史窗左侧按「全部 / 窗口截图（下挂各进程）/ 常规截图 / 早期未分类」分组，并显示每组张数；右侧只加载当前分类的缩略图，「全部」最多展示 120 张以免一次解码过多。
- **每个分类**默认保留 30 张：窗口截图下每个进程各 30 张，常规截图、早期未分类各 30 张。可在「设置 → 常规 → 每个分类保留张数」改为 1–200，改小后立即按新上限清理，没有云同步、没有上传。
- 在「设置 → 常规」用「保存最近截图到本机」开关控制；关闭后不再写入新文件，但**不会删除已有历史**。
- 「打开截图历史」或托盘菜单「截图历史…」打开管理窗：复制（写回剪贴板）、贴图、标注、另存为、删除、清空当前分类、全选、打开文件夹；「另存为」按选中数量自动切换单张/批量。
- 多选语义：「复制」取最新一张写入剪贴板；「标注」取最新一张贴到桌面并进入标注；「贴图」把所有选中项依次贴出（按 24px 阶梯错开）；「删除」删除全部选中项。列表支持 Ctrl/Shift 多选，双击条目可直接复制。
- 全选是开关：第一次点「全选」选中当前分类全部，按钮变成「取消全选」，再点一次退出多选；选择模式下点列表空白处也会退出。窗口打开期间新截图会即时出现在列表里，底栏上方固定显示操作说明，不弹出 tooltip；按 `Esc` 关闭窗口。
- 贴图按钮直接使用历史文件创建贴图，不经过剪贴板，不会覆盖你当前复制的内容。

## 延时截图与鼠标指针

### 延时截图

延时截图就是「按下截图热键后，先等几秒，再冻结画面」。它解决的是普通截图来不及摆好的场景：

- 想截右键菜单、悬停提示、下拉框、Toast 通知：按下热键后再去把菜单打开，倒计时结束才会冻结，菜单就在画面里。
- 想截窗口的某个状态：先把鼠标移到目标位置、等动画停住，再让截图落下来。
- 想摆好多个窗口：按下热键后还有几秒钟可以调整。

用法：在「设置 → 常规 → 延时截图」选 `3 秒 / 5 秒 / 10 秒`，然后按截图热键；等待期间再按一次截图热键会取消。托盘菜单的「延时截图」入口也可以直接触发，未配置时默认 3 秒。倒计时期间可以正常操作，程序只会在到点后抓取一次画面。

### 鼠标指针

打开「设置 → 常规 → 截图包含鼠标指针」后，冻屏取景和全屏快速截图都会在冻结画面里画上当前指针；默认关闭。指针只在截图那一刻采样一次，不会跟踪移动。

## 另存为

- **取景器**：框选后按 `Ctrl+S` 或点选区右上角「保存」，可选 PNG/JPEG；保存成功后同时复制到剪贴板并写入截图历史，然后关闭取景器。
- **截图历史**：选中一张点「另存为」，把历史原图另存到任意位置；选中多张再点同一个「另存为」，会一次性导出到一个文件夹（重名自动加后缀）；点「标注」会直接创建贴图并进入标注模式，不经过剪贴板。
- **贴图**：右键菜单「另存为…」；标注过程中点工具栏「另存」会先烘焙标注，再复制并另存。
- 系统另存为对话框由 Windows 提供，文件名默认形如 `IshWY-shot-20261020-130000.png`；取消不会改动剪贴板或历史。

## 内存与体积

截图工具会为了「按下热键立刻出图」保留少量常驻资源，当前取舍：

- 冻屏取景器关闭时会释放两张 2560×1600 级别的位图（WriteableBitmap 与 GDI Bitmap）并主动 GC，不会随每次截图累积。取景器亮起时会按当前光标位置立即识别窗口，不需要先晃动鼠标。
- 贴图不再常驻一份全分辨率解码位图；平时只保留压缩 PNG 与当前窗口尺寸的显示 DIB，标注时复用同一块 DIB 绘制，避免每次鼠标移动分配全窗口位图。按需解码也不再复制第二份全分辨率位图。
- 贴图滚轮放大的上限是当前显示器工作区，不会把窗口放大到屏幕外导致显存/内存暴涨。滚轮期间只提交占位边框，停手 350ms 后才做一次高清重绘；不再为每个中间尺寸先 `MoveWindow` 再 `UpdateLayeredWindow`（后者的 `psize` 本身就会调整窗口尺寸），100% 不透明度走 `SourceCopy` 直拷，缩回较小尺寸后还会把曾经按最大尺寸分配的 DIB 回收重建。贴图拖动期间加 `SWP_NOREDRAW`，减少拖动时反复提交表面。
- 需要说明的是：真正省显存的做法是让贴图窗口只覆盖「可见区域」，屏幕外部分不分配表面。现在的实现仍是整窗尺寸的分层表面，所以把贴图放大到接近工作区时，峰值仍会高于静止状态；这部分是否继续改造取决于实测结果。
- 截图历史窗口关闭时释放全部缩略图。
- WGC 显示器常驻池（约 3 张帧缓冲，2560×1600 下约 48 MB）**有意保留**：它让第一次按截图热键就能立即拿到冻结帧且不闪屏。贴图移动、标注、OCR 之后，程序会尽量回收编辑用的缩放基底与 OCR 流对象；但该常驻池和最近一次贴图的显示 DIB 仍会保留，因此重操作后可能停在比空闲更高的水位。本机实测：空闲/截图后约 142 MB，移动贴图、标注或 OCR 后约 177 MB，重复操作峰值约 200 MB；停止操作约 5 分钟后，Windows 工作集裁剪/GC 会让进程回落到约 100 MB。这是系统回收与常驻池共同作用，不是随操作次数无限累积的泄漏。
- 发布脚本会删除 Windows App SDK 元包里从未加载的 AI/ML/Search/Widgets/WebView2/调试组件（57 个文件，约 65 MB）、37 个 `.winmd` 元数据文件（约 2.4 MB）以及只保留 4 个语言目录（约 3.2 MB）；并用 `PublishTrimmed=true` + `TrimMode=partial` 裁掉未引用的托管程序集。当前发布目录约 72.7 MiB，zip 约 29.2 MiB。

本机 2560×1600 实测：空闲与普通截图后约 142 MB；贴图移动、标注、OCR 后可能到约 177 MB，重复操作峰值约 200 MB，停止操作约 5 分钟后回落到约 100 MB。主要常驻开销是上面提到的 WGC 池和当前贴图的显示表面；回落到 100 MB 是 Windows 对闲置工作集的裁剪，之后再次操作会重新升高。实际内存随屏幕分辨率、贴图数量与历史缩略图数量变化，请以任务管理器中的 `IshWY.exe` 为准。

## 配置说明

`data/config.json` 常用字段：

修饰键位掩码统一为：Alt=1、Ctrl=2、Shift=4、Win=8（可相加，例如 6 = Ctrl+Shift，3 = Ctrl+Alt）。

| 字段                                           | 说明                                                                                                                     |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `hotkeyVk`、`hotkeyModifiers`              | 窗口截图热键的虚拟键码与修饰键（默认：65 = A，1 = Alt；`0` 回退旧字段 `hotkeyKey`，`-1` 表示用户已删除、不再回退） |
| `hotkeyKey`                                  | 旧版截图键名（`F1`…`F12`），仅在 `hotkeyVk=0` 时生效                                                              |
| `fullHotkeyVk`、`fullHotkeyModifiers`      | 全屏快速截图热键（默认：68 = D，1 = Alt；`-1` 表示用户已删除，不回退 `fullScreenHotkeyKey`）                         |
| `pinHotkeyVk`、`pinHotkeyModifiers`        | 从剪贴板贴图热键（默认：86 = V，3 = Ctrl+Alt）                                                                           |
| `ocrHotkeyVk`、`ocrHotkeyModifiers`        | 从剪贴板 OCR 热键（默认：83 = S，3 = Ctrl+Alt）                                                                          |
| `captureProfile`                             | 截图档位：`normal`（默认，冻屏取景）/ `quick`（快捷全屏）                                                            |
| `modeHotkeyVk`、`modeHotkeyModifiers`      | 切换截图档位的全局热键（默认：67 = C，5 = Alt+Shift）                                                                    |
| `saveHistory`                                | 是否把框选/全屏截图写入 `data/history`（默认 `true`）                                                                |
| `historyPinCrop`                             | 贴图裁剪结果是否写入历史「贴图裁剪」分类（默认 `true`）                                                                |
| `pinInitialScale`                            | 新贴图与左右切换到的历史图片的初始大小，原图百分比 `80`–`100`，默认 `100`；超出工作区仍会自动缩小                 |
| `historyPerCategory`                         | 截图历史每个分类（窗口按进程、常规/早期各一组）保留的张数，`1`–`200`，默认 `30`                                   |
| `captureDelaySeconds`                        | 截图热键的延时秒数：`0`（默认）/ `3` / `5` / `10`                                                                |
| `captureCursor`                              | 截图是否包含鼠标指针（默认 `false`）                                                                                   |
| `defaultCaptureMode`                         | 每次按截图热键的起始模式：`normal`（默认，所见即所得）/ `window`（抗遮挡）                                           |
| `preferUmiOcr`、`umiOcrPort`               | 是否优先 Umi-OCR（默认 `false`，用 Windows OCR）及其端口（默认 1224）                                                  |
| `backgroundImagePath`、`backgroundOpacity` | 设置窗背景图与不透明度                                                                                                   |

> 开机自启动状态不写入 `config.json`，而是存在上面提到的 HKCU Run 项里。

## 已知限制

- **独占全屏游戏**：全屏截图会先抢前台，让游戏退出独占全屏再采集（日志中可见 `FullscreenBypass:`）。多数游戏可成功，但属于 best-effort；若截到的是桌面，请把游戏改为「无边框窗口 / 全屏窗口」模式。游戏内组合键已实测可用。
- **多显示器不同 DPI**：跨屏缩放与坐标换算仍在完善，混合 DPI 环境可能出现位置偏差。
- 仅提供 **x64** 构建。
- 取景器支持 `Ctrl+S` 或选区右上角「保存」另存为 PNG/JPEG；保存成功后仍会复制到剪贴板并写入历史。回车/双击仍然只是复制并写历史。
- 截图历史是本机明文 PNG，删除/清空后不可恢复；关闭保存开关不会清理旧文件。没有伴随 `.json` 元数据的截图会归入「早期未分类」，无法再区分当年是窗口截图还是常规截图。

## 隐私

所有截图、OCR、标注与截图历史均在本地完成，程序不发送任何遥测或网络请求。截图历史只写入程序目录 `data/history`，不会上传。唯一的网络访问是**可选**的 Umi-OCR：仅在手动开启后连接本机 `127.0.0.1:<端口>`（默认 1224），未启用或未运行时自动跳过。
