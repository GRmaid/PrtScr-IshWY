本项目是基于 .NET 10 / Windows App SDK 2.5（WinUI 3）/ CsWin32 的 Windows 截图工具，MIT 协议。它还原微信截图的顺手体验，并补上窗口被遮挡时也能截到窗口本体的能力；另带贴图、标注、OCR、全屏快速截图与截图历史。

## 特性

- **截图**：热键唤起冻屏取景器，支持「窗口截图 / 常规截图」两种模式。窗口模式重建窗口本体、抗遮挡；常规模式所见即所得，菜单、悬停提示、下拉框和鼠标指针都能截。框选支持八向缩放、拖动移动、整窗选区、滚轮或 `[` `]` 切窗；底部 HUD 实时提示操作，`Tab` 临时切模式；可设 3/5/10 秒延时与是否包含鼠标指针。
- **贴图与标注**：截图钉在桌面最上层，逐像素透明；可拖动、滚轮以指针为中心缩放、8px 吸附、左右半屏切历史图。右键菜单提供锁定、点击穿透、透明度、复制、标注、裁剪、OCR、另存为和打开历史；标注支持矩形、箭头、画笔、文字、马赛克、序号、撤销与清空；「屏幕贴图管理」可集中复制、另存、OCR、关闭。
- **贴图来源**：设置可选剪贴板优先（图片 → 文字）/ 只贴最新截图 / 只贴剪贴板文字 / 关闭；剪贴板是文字时生成可换背景色的文字卡片。
- **截图历史**：每次确认截图写入本机 `data/history`，带同名 JSON 元数据；按模式 / 进程分类，每类默认保留 30 张（1–200 可调）。历史窗支持复制、贴图、标注、另存为、删除、清空分类、全选；多选可整批拖到资源管理器、微信、文档等外部程序，落地为真实 PNG，原图与剪贴板不变。
- **OCR**：默认内置 Windows OCR，零依赖；可手动开启本机 Umi-OCR（默认端口 1224）提升精度。取景中按 `O`、贴图右键、托盘或设置均可触发；结果窗可编辑复制。
- **全屏与游戏**：任意组合键静默整屏进剪贴板；支持「常规取景 / 快捷全屏」两档，`Alt+Shift+C` 运行中切换。全屏游戏里默认直接抓整屏、不弹取景器，先抓帧，只有首帧黑屏才短暂抢前台，避免闪屏和游戏声音中断。
- **提示与热键**：切换档位、截图成功或失败时在屏幕角落淡入纯文字提示，不抢焦点；字号、材质、透明度、时长、位置和文案均可调。七项全局热键可录制、删除、单项恢复或全部恢复；取景器内另有 `[` `]` 切窗。
- **便携与隐私**：配置、日志、历史都在程序目录 `data/`，解压即用；默认不写注册表，只有手动开启开机自启动时才写当前用户 Run 项。截图、OCR、标注与历史全部本地完成，不上传、不遥测；唯一网络访问是可选的本机 Umi-OCR。

## 下载与运行

当前最新版本：**v1.3.0**。从 [Releases](https://github.com/GRmaid/PrtScr-IshWY/releases/latest) 下载 `IshWY-1.3.0-win-x64.zip`，解压后双击 `IshWY.exe`，程序驻留托盘。

- 系统：Windows 10 2004（build 19041）或更高，x64；发布包 self-contained，源码构建需要 .NET 10 SDK。
- 数据：配置 `data/config.json`、日志 `data/logs/app.log`、历史 `data/history/`；退出在托盘菜单。

> 程序未做代码签名，SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。

## 默认热键

| 操作 | 默认按键 |
| --- | --- |
| 窗口截图（冻屏取景） | `Alt+A` |
| 全屏快速截图 | `Alt+D` |
| 贴图 | `Alt+S` |
| 从剪贴板识别文字 | `Alt+Q` |
| 切换截图档位 | `Alt+Shift+C` |
| 上一个 / 下一个窗口（仅取景器） | `[` / `]` |
| 取消取景 / 退出标注 / 关闭贴图 / 关闭 OCR | `Esc` 或鼠标右键 |
| 确认选区 | `Enter` 或双击 |
| 取景器内另存为 | `Ctrl+S` |
| 取景中识别文字 / 切模式 / 复制色值 | `O` / `Tab` / `Ctrl+C` |

全局热键在「设置 → 快捷键」里点「修改」后直接按新组合键；`F1`–`F12` 可单用，其他键需搭配 Ctrl / Alt / Shift / Win。每行右侧 ↻ 恢复单项，✕ 删除；删除后显示「未设置」，重启不会复活。

## 快速上手

- 按 `Alt+A` 进入取景，`Tab` 切窗口/常规模式，拖拽框选，`Enter` 确认，`Esc` 取消；滚轮切重叠窗口。
- 按 `Alt+S` 贴图：拖动移动、滚轮缩放、左右半屏切历史图、右键打开标注/裁剪/OCR 等菜单。
- 历史窗右键进入多选，之后左键勾选；已选卡片可整批拖到其他软件，删除与清空会先确认。

## 设置

左侧十页导航：主页 / 快捷键 / 截图行为 / 贴图 / 提示 / 截图历史 / 启动与托盘 / 外观 / OCR 引擎 / 关于；窄窗自动收成图标栏。配置文件 `data/config.json` 由设置页写入，常用项为 `pinBehavior`、`pinTextBackground`、`historyPerCategory`、`defaultCaptureMode`、`captureDelaySeconds`，一般不需要手改。

## 构建与测试

需要 .NET 10 SDK（`winget install Microsoft.DotNet.SDK.10`）：

```powershell
dotnet build PrtScr.sln -c Debug
```

运行：

```powershell
./src/PrtScr.App/bin/x64/Debug/net10.0-windows10.0.22621.0/win-x64/IshWY.exe
```

冒烟测试（启动 3 秒后自动退出，退出码 0 表示启动成功）：

```powershell
dotnet run --project src/PrtScr.App -- --smoke
```

单元测试：

```powershell
dotnet test PrtScr.sln -c Debug
```

> 构建前请先退出正在运行的 IshWY，否则 exe 被占用会构建失败。

## 打包便携版

```powershell
pwsh scripts/publish.ps1 -Version 1.3.0
```

产物为 `artifacts/IshWY-1.3.0-win-x64/` 与同名 zip。脚本会检查 `IshWY.pri`、`.xbf` 并默认执行一次 `--smoke`；无交互桌面的 CI 可加 `-SkipSmoke`。

## 内存与体积

- WGC 显示器常驻池约 3 张帧缓冲（2560×1600 下约 48 MB）**有意保留**，换取按热键立即出冻结帧且不闪屏。
- 贴图只保留压缩 PNG 与当前窗口尺寸的 DIB；滚轮缩放停手 350ms 后才高清重绘，缩回较小尺寸会回收 DIB。本机实测空闲约 142 MB，重操作后约 177 MB，峰值约 200 MB，停止约 5 分钟回落到约 100 MB。
- 发布包约 72.9 MiB / zip 约 29.2 MiB；`publish.ps1` 会裁掉未加载的 App SDK 组件、`.winmd` 和多余语言目录。

## 已知限制

- **独占全屏游戏**：全屏截图先直接抓帧，只有首帧黑屏或不可用时才短暂抢前台重试；仍属 best-effort。若截到桌面，请把游戏改为「无边框窗口 / 全屏窗口」。
- **多显示器不同 DPI**：跨屏缩放与坐标换算仍在完善，混合 DPI 环境可能有位置偏差。
- 仅提供 **x64** 构建；历史是明文 PNG，删除/清空后不可恢复。
- 提示背景是弹出瞬间的冻结快照，显示期间不实时刷新；抓屏失败时回退为半透明纯色。

## 隐私

所有截图、OCR、标注与历史都在本地完成，不上传、不遥测。唯一网络访问是**可选**的本机 Umi-OCR：仅在手动开启后连接 `127.0.0.1:<端口>`（默认 1224）。
